# Workflow catalog

All three graphs are inactive manual demonstrations with synthetic input, generated by `npm run generate`. None is a production export. No live IDs, credentials, pinned execution data or external destinations are required.

| Workflow | Purpose | Reusable behavior | Limitation |
|---|---|---|---|
| [lead-intake](../workflows/lead-intake.json) | Normalize and route a contact | Strict input, canonical email, explicit route | Does not create a CRM record |
| [monthly-report](../workflows/monthly-report.json) | Compute comparable metrics | Deterministic calculations, zero-baseline handling | Does not fetch analytics or send reports |
| [incident-triage](../workflows/incident-triage.json) | Choose the next response to a failure | Bounded retry recommendation, explicit terminal state | Does not perform a retry or notify an operator |

The gateway's bounded adapter-retry test is separate from the incident-triage graph's recommendation. Its persistent idempotency ledger is also separate from n8n's execution history. Do not attribute gateway guarantees to a manually imported graph.
